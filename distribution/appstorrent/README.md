# Verto — комплект для appstorrent

Готовые материалы для карточки приложения. Ничего не публикуется автоматически:
проверьте поля и отправьте их через форму каталога.

## Состав

```
distribution/appstorrent/
├── description-ru.txt       # полное описание, чистый текст
├── submission.md            # готовые поля формы и ссылки
├── download-url.txt         # ссылки на DMG/ZIP/changelog
├── changelog.md             # текст изменений 0.3.1
├── screenshots/
│   ├── 01-ru-to-en.png      # 720×600, RGB
│   ├── 02-en-to-ru.png      # 720×600, RGB
│   └── 03-settings.png      # 720×600, RGB
└── assets/
    ├── icon-1024.png        # 1024×1024, RGBA
    ├── icon-1024-flat.png   # 1024×1024, RGB
    ├── background-742x360.png
    └── background-1484x720.png
```

## Перед отправкой

1. Убедитесь, что релиз `v0.3.1` опубликован и в нём есть оба ассета: `Verto-0.3.1.dmg` и `Verto-0.3.1.zip`.
2. Проверьте ссылки из `download-url.txt` в браузере без авторизации.
3. Вставьте `description-ru.txt` в поле описания. В тексте намеренно нет ссылок и эмодзи.
4. Загрузите иконку, фон и три скриншота.
5. Укажите разработчика: Павел Бобро (Pavel Bobro).

## Про формат

Каталог просит DMG, поэтому он подготовлен. Для неподписанного приложения ZIP
безопаснее: DMG с карантином может не смонтироваться и macOS назовёт его
«повреждённым». Если каталог принимает ZIP, используйте его как основной вариант.

Приложение ad-hoc signed; платного сертификата Apple нет. Пользователь может
увидеть предупреждение Gatekeeper и должен открыть приложение через
**System Settings → Privacy & Security → Open Anyway**.
